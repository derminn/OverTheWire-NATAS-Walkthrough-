## What is Natas?

Natas is a web-based security wargame designed to teach the fundamentals of 
server-side web security. Each level presents a vulnerable website, and the 
goal is to find the password for the next level by exploiting weaknesses in 
the page — without any installation or setup required, just a browser and 
curiosity.

It covers concepts like:
- Exposed source code and hidden HTML comments
- HTTP headers and cookies manipulation
- Basic authentication bypass
- Directory traversal
- Server-side logic flaws
